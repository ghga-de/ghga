# metldata

metldata - A framework for handling metadata based on ETL, CQRS, and event sourcing.

## Installing

```
helm install metldata oci://registry-1.docker.io/ghga/metldata-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/libs/metldata). See
[values.yaml](values.yaml) for the full set of configurable values.
