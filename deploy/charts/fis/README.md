# fis

File Ingest Service - A service to liaise between Central File Services and Data Hubs for file inspection.

## Installing

```
helm install fis oci://registry-1.docker.io/ghga/fis-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/fis). See
[values.yaml](values.yaml) for the full set of configurable values.
