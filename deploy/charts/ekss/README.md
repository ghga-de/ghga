# ekss

Encryption Key Store Service - providing crypt4gh file secret extraction, storage and envelope generation

## Installing

```
helm install ekss oci://registry-1.docker.io/ghga/ekss-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/ekss). See
[values.yaml](values.yaml) for the full set of configurable values.
