# dhfs

Data Hub File Service - a service enabling file inspection and re-encryption at Data Hubs

## Installing

```
helm install dhfs oci://registry-1.docker.io/ghga/dhfs-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/datahub-file-service). See
[values.yaml](values.yaml) for the full set of configurable values.
