# wps

Work Package Service - a service for authorizing downloads of dataset files and uploads of research data.

## Installing

```
helm install wps oci://registry-1.docker.io/ghga/wps-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/work-package-service). See
[values.yaml](values.yaml) for the full set of configurable values.
