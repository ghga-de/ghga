# rts

Reverse Transpiler Service - A service running a REST API that serves accessioned metadata files by study ID

## Installing

```
helm install rts oci://registry-1.docker.io/ghga/rts-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/reverse-transpiler-service). See
[values.yaml](values.yaml) for the full set of configurable values.
