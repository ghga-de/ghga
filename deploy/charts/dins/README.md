# dins

Dataset Information Service - Providing public metadata about files registered with the Internal File Registry

## Installing

```
helm install dins oci://registry-1.docker.io/ghga/dins-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/dataset-information-service). See
[values.yaml](values.yaml) for the full set of configurable values.
