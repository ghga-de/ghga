# ars

Access Request Service - a service for managing requests for access to GHGA datasets.

## Installing

```
helm install ars oci://registry-1.docker.io/ghga/ars-chart
```

## Source

Part of the [GHGA monorepo](https://github.com/ghga-de/ghga/tree/main/services/access-request-service). See
[values.yaml](values.yaml) for the full set of configurable values.
